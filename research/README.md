# Research

独立研究不是对工程经验的包装，而是从真实问题中提取可证伪问题，通过实验获得有边界的新判断。

- `questions/`：长期问题、竞争解释和验证路线；
- `experiments/`：实验设计、运行信息和原始结果索引；
- `findings/`：经过验证但仍明确边界的阶段性结论；
- [`model-intelligence/`](model-intelligence/README.md)：持续研究新视觉底座、VLM/VLA 视觉编码和端侧可迁移价值。

研究条目必须区分“已有公开结论”“工程观察”和“本人的新推断”。当前入口：

- [DMS eye visibility and localization reliability](questions/dms-eye-visibility-and-localization-reliability.md)
- [Visual model intelligence](model-intelligence/README.md)
