# IP policy

“个人编写”不等于“个人拥有”。工作任务、公司设备或公司资源下产生的内容，默认按严格边界处理。

## Forbidden

- 公司源代码及其改写、翻译或结构性复刻；
- 未公开的数据、模型、权重、参数、架构、客户和供应商信息；
- 能通过指标、目录、日志或组合描述反推出具体项目的内容；
- 权属不清的所谓通用代码；
- 凭据、内网地址、真实人员信息及带敏感历史的 Git 内容。

## Allowed with independent provenance

- 抽象后的问题机制和方法论；
- 使用公开或自建数据重新进行的独立验证；
- 在个人环境中从零实现、不依赖公司资产的通用工具；
- 已公开资料的引用、批判和复现，但须遵守许可证与引用要求。

公开前必须重新检查当前文件和完整 Git 历史；删除工作树中的敏感内容不足以清除历史。存在疑问时不公开。
