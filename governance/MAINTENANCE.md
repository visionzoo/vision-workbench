# Governance maintenance

## Create

只有跨模块长期生效的边界、质量门、生命周期、IP 规则或重要结构决策进入 Governance。操作建议应进入相应模块。

## Add or update

规则修改必须说明触发问题、影响范围、迁移要求和验收方式；实质性结构变化新增 decision record。避免同一规则在多文件重复表述。

## Supersede or remove

冲突规则先确定权威版本，再标记 superseded 并迁移引用；不得直接删除仍影响现有内容的规则。

## Verify

检查规则间冲突、状态域混用、不可执行要求、过重模板和 Agent 是否能找到入口。
