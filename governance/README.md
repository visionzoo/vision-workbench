# Governance

这里定义母库的边界和最低质量标准。规则的目的不是增加文档负担，而是阻止未经验证的材料进入长期知识区。

- [Scope](scope.md)：收录范围与专题剥离边界
- [Content standard](content-standard.md)：证据、术语、元数据和结论要求
- [IP policy](ip-policy.md)：公司资产、版权和公开边界
- [Lifecycle](lifecycle.md)：内容及公共项目的状态流转
- [Decision records](decisions/)：只记录会长期影响仓库结构的决定
- [Agent contract](../AGENTS.md)：Agent 在本仓库中必须遵循的操作门槛

规则发生实质变化时，应新增 decision record 并说明原因；不要用无解释的目录调整或模板膨胀替代治理。
