# Foundations

基础理论按“机制为主、模型索引为辅”组织，目标是解释为什么有效、在什么条件下失效，以及如何支持工程决策，而不是穷举模型。

## Primary views

- `mechanisms/`：表征、多尺度、感受野、归纳偏置、注意力、迁移、优化与泛化等机制；
- `tasks/`：检测、分类、关键点、分割、跟踪等任务的目标、评价和误差结构；
- `model-index/`：YOLO、ResNet、MobileNet、ViT、DETR、CLIP 等模型族到机制/任务条目的双向索引。

新增模型条目前先回答：它改变了什么机制或约束？若只是版本更新或结构差异，应进入既有条目的比较表，而不是创建孤立笔记。
