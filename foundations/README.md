# Foundations

基础理论按“机制为主、模型族为结构化索引”组织，目标是解释为什么有效、在什么条件下失效，以及如何支持工程决策，而不是穷举模型。

## Structure

- `mechanisms/`：表征、多尺度、感受野、归纳偏置、注意力、迁移、优化与泛化等机制；
- `tasks/`：检测、分类、关键点、分割、跟踪等任务的目标、评价和误差结构；
- [`model-index/`](model-index/README.md)：模型族到机制、任务、评测与部署条目的双向索引。

当前只建设一个完整样板：[YOLO family](model-index/families/yolo/README.md)。在核验目录粒度、证据质量和维护成本前，不批量扩展其他模型族。

## Source rule

优先级依次为：原作者论文及补充材料、原作者/维护组织文档和模型卡、官方代码与 Release、官方数据集/评测页面、硬件厂商正式部署文档、第三方复现与工程证据。后两类不得混入“官方披露”。

官方指标只表示“官方报告结果”，必须绑定模型、权重、数据集版本、split、输入尺寸、精度、硬件、软件版本和计时范围；缺少的信息写 `not disclosed`，不得推断补齐。

新增、补充、拆分、合并和删除规则见 [MAINTENANCE.md](MAINTENANCE.md)。
