# Model index

模型索引按“模型族”组织，用于回答四个问题：

1. 该族由谁提出和维护，哪些版本属于不同分支；
2. 结构、训练和评价条件发生了什么实质变化；
3. 哪些结论来自官方，哪些来自第三方或本人验证；
4. 选择、导出、量化和部署时需要核对什么。

统一比较维度见 [comparison-axes.md](comparison-axes.md)，模型族登记见 [registry.yaml](registry.yaml)。

当前唯一完整样板是 [YOLO](families/yolo/README.md)。其他模型族在 YOLO 样板完成粒度和维护成本复盘后再建立。
