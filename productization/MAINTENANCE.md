# Productization maintenance

## Create

只有明确用户、工作流、替代方案、可测价值和验证路径时才创建 use case 或 opportunity；market case 必须有可核验事实来源。

## Add or update

事实、推断和假设分开；补充购买者、交付边界、数据/部署/销售约束、单位经济性、主要反证和最低成本验证。

## Split or merge

购买者、价值链或交付模式不同则拆分；同一问题的多个技术方案放在一个机会条目比较。

## Remove

没有视觉技术关联、无法合法验证或已满足放弃条件的内容移出；保留放弃原因，避免重复投入。

## Verify

不能把技术可行、用户称赞、单次试用或市场规模叙述直接等同于付费需求。
