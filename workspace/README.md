# Workspace

工作区只容纳尚不能归类的短期输入，不承担知识生命周期。

- `inbox/`：未分类的问题、材料与线索；这些内容不可作为已验证知识引用。
- 不设置 `working/`：一旦主题可归类，就直接在 foundations、engineering、research 或 productization 的对应目录创建 `status: working` 条目。
- 无法在合理时间内归类或继续处理的材料，应删除、移出仓库或明确记录放弃原因，避免永久堆积。

原始大数据、模型权重、公司材料和可能公开的项目代码不放在这里。文件状态的变化遵循 [Lifecycle](../governance/lifecycle.md)，不通过移动或复制文件表达。
